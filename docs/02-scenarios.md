## 정상 흐름
S1. 학생 과목별 다시 볼 주제
1. 김가온이 "수학 · 문제 풀기"로 학습 시작 → 기록 → 마치기.
2. AI가 주제 "이차함수 그래프"를 찾고 확인 테스트 5문항 중 1개 정답.
3. 결과 아래 "다시 볼 주제: 수학 - 이차함수 그래프"가 보임.
4. 학생 홈에 과목별로 묶여 남음(수학 아래 최대 3개).

S2. 교과 교사 주간 집계
1. 오수학 로그인 → 사이드바 "내 과목" → 카드 "2학년 3반 수학", "2학년 4반 수학".
2. 3반 카드: 이번 주 수학 학습 12회 · 학생 7명, 다시 볼 후보가 많은 주제 "이차함수 그래프 4명".
3. 반·과목 화면 → 주제 표, 많이 틀린 문항 2개, 동의 학생 목록.

S3. 교과 교사 개별 열람·피드백(선택)
1. 오수학이 목록에서 김가온 선택 → 김가온의 수학 학습만 보임(국어 학습 없음), 열람 기록이 남음.
2. 돌아보기에 피드백 작성 → 김가온 홈 '새 피드백'에 "수학 선생님" 표시.
3. 한담임이 김가온 상세에서 같은 피드백을 "수학 선생님" 표시와 함께 봄.

S4. 학생 동의
1. 김가온이 동의 설정에서 "교과 선생님에게 공개"를 켬 → 이후 수학 학습이 오수학 집계·목록에 포함.
2. 끄면 바로 제외(집계·목록·상세 모두).

E1. 미동의 학생: 이나래(미동의)의 수학 학습은 오수학 집계 숫자·목록에 없음. 담임 한담임은 기존 규칙대로 봄.
E2. 다른 과목: 김가온의 국어 학습은 오수학에게 안 보임(주소를 직접 쳐도 빈 결과).
