# 성장 페이스 — 1분 주요 기능 영상 시나리오 (2026-11-14)

## 0. 원칙
- 1분 안팎, **주요 기능만**: 학생이 스스로 학습을 기록하고 → AI가 주제·확인 테스트로 돌아보게 하고 → 선생님은 반과 과목 단위로 챙긴다.
- 부가 기능(마일리지, 도움말, CSV, 메모, 신고 등)은 넣지 않는다.
- 실제 모드(5173, 실제 백엔드)에서 녹화. 아직 실제 백엔드에 없는 것(QR 인증, 교과 교사, 질문 핵심)은 **영상에서 빼거나 mock 장면을 짧게 붙인다**(아래 6절).

## 1. 녹화 전 준비 (사용자)
1. 내장 브라우저(또는 녹화할 브라우저)에서 실제 모드 `http://localhost:5173` 열기.
2. 로그인 공간 3개를 준비(같은 주소 탭은 로그인 정보를 함께 써서 나중 로그인이 앞을 덮어씀):
   - 학생: `http://localhost:<포트>` → `student01@growth-pace.test`
   - 담임: `http://[::1]:<포트>` → `teacher@growth-pace.test`
   - 교과 교사: `http://subject.localhost:<포트>` → `subject@growth-pace.test` (이교과, 2학년 3반 수학)
   - 비밀번호는 직접 입력(교과 교사 비밀번호는 Supabase 대시보드에서 설정해 팀 채널로만 공유). 녹화 중에는 **로그아웃을 누르지 않는다**(실제 모드 로그아웃은 같은 계정의 다른 로그인도 끊음).
   - 세 주소는 로그인이 따로 저장돼 한 브라우저 탭 3개로 녹화할 수 있다(`127.0.0.1`은 이 개발 서버가 받지 않음).
3. 학생01에 진행 중인 학습이 없게 하기(있으면 먼저 끝내기).
4. 화면 크기 1440×900 권장, 브라우저 확대 100%.
5. AI가 오래 걸리는 단계(첫 확인 테스트 출제 약 13초, AI 답변 약 5초)는 녹화 후 잘라 낸다. 잘라 낼 지점은 표의 ✂ 표시.

## 2. 1분 시나리오 — "학생의 학습이 선생님에게 이어지고, 선생님은 문제를 본다" (실제 모드)
핵심 메시지: 학생이 남긴 학습(기록·질문·확인 테스트)이 **바로** 담임·교과 선생님 화면으로 연동되고, 선생님은 **어떤 문제에서 막히는지**를 본다.

| 시간 | 화면(탭) | 동작 | 자막·내레이션 (예시) |
|---|---|---|---|
| 0:00–0:06 | 학생 · 학습 시작 | 과목 태그 **수학** → "이차함수 꼭짓점 복습" → QR 만들기 → (키오스크 탭) 입력·Enter → 학습 화면 | "과목을 정하고 교실 단말기에 QR을 찍어 학습을 시작해요." |
| 0:06–0:16 | 학생 · 학습 중 | 메모 "완전제곱식으로 바꾸면 꼭짓점이 보인다" → 궁금한 점 "판별식과 꼭짓점은 어떤 관계?" → AI 도우미 질문 ✂(답변 대기) | "공부하며 알게 된 것과 궁금한 점을 남겨요." |
| 0:16–0:28 | 학생 · 마치기 | 학습 끝내기(QR) → AI 주제 카드 선택 → 테스트 보기 ✂(출제 대기) → 5문항 응답 → 결과 "다시 볼 주제: 수학 - 이차함수 꼭짓점" → 돌아보기 저장 | "AI가 기록에서 주제를 찾고, 확인 테스트로 어디가 약한지 알려 줘요." |
| 0:28–0:38 | 담임 · 반 대시보드 → 학생 상세 | 학생01 행에 **방금 학습이 반영**(시각·정답률) → 학생 상세 → 방금 메모·질문, 테스트 결과 → 피드백 한 줄 | "학생의 학습이 바로 담임 선생님 화면에 이어져요." |
| 0:38–0:54 | 교과 교사 · 맡은 과목 | 맡은 과목 → 수학 → 2학년 3반: **주제별 학습(다시 볼 후보)** → **많이 틀린 문항** → **이번 주 질문 핵심**(꼭짓점 5명, 독립·배반 사건 4명) | "교과 선생님은 자기 과목에서 학생들이 많이 틀린 문제와 공통으로 묻는 질문을 한눈에 봐요. 이름과 원문은 보이지 않아요." |
| 0:54–1:00 | 학생 · 홈 | "새 피드백 1" → 피드백 확인 | "선생님의 피드백이 다시 학생에게 돌아가요." |

## 3. 내레이션 마무리 (선택, 3초)
"기록 → 돌아보기 → 선생님 피드백, 학생의 성장 속도에 맞춘 자기주도학습."

## 4. 실제 모드 마무리 테스트 체크리스트 (녹화 전)
| # | 확인 | 기대 결과 | 결과 |
|---|---|---|---|
| 1 | 학생 로그인 후 홈 | 오늘 할 일·최근 7일·Pace 카드가 오류 없이 보임 || ✅ 오류 없음 |
| 2 | 학습 시작(과목 태그 수학) → 인증 | 실제 모드는 "인증 건너뛰기(개발용)"로 시작, 학습 화면 제목 "수학 · …" || ✅ 건너뛰기로 시작, 제목 "수학 · 이차함수 꼭짓점 복습" |
| 3 | 메모·궁금한 점 기록 | 오늘의 기록에 바로 표시, '교사 공개' 표시 || ✅ 메모·궁금한 점 모두 교사 공개로 표시 |
| 4 | AI 도우미 질문 | 5초 안팎 답변, 정답을 바로 주지 않음 || ✅ 5.1초, 개념 설명형 답변 |
| 5 | 학습 끝내기 → 주제 | 주제 1~3개(근거 문구 포함) || ✅ 4.1초, 주제 1개 + 근거 2개 |
| 6 | 확인 테스트 | 첫 출제 10~15초, 5문항, 제출 후 결과·해설 || ✅ 주제 선택 후 8.1초에 5문항, 결과 1/5·해설·"다시 볼 주제: 수학 - 이차함수 꼭짓점" |
| 7 | 돌아보기 저장 | 기록 화면으로 이동, 오류 없음 || ✅ 기록 화면으로 이동(실제 모드라 마일리지 창 없음 — 의도) |
| 8 | 세션 과목 저장 | 교사 화면에서 그 학습이 "수학"으로 보임(`sessions.subject`) || ✅ 교사 학생 상세에 "수학 · 이차함수 꼭짓점 복습" (교과 교사 노출은 12번에서) |
| 9 | 교사 대시보드 | 표·배너·위젯 정상, 학생01 최근 학습 반영 || ✅ 학생01 행: 4회·20%·오후 02:25·피드백 기다림 |
| 10 | 학생 상세 | 공개 기록만 보임('나만 보기' 없음), 열람 기록 남음 || ✅ 공개 기록 2개, 학생 동의 화면 열람 기록에 오후 02:27 남음 |
| 11 | 피드백 보내기 → 학생 홈 | 학생 홈 '새 피드백' 표시 || ✅ 학생 홈 "새 피드백 1" |
| 12 | 교과 교사(이교과) 맡은 과목 | 메뉴 '맡은 과목' → 수학 탭 → 반 탭 이름이 실제 반 이름(ID 아님) → 질문 핵심 OK·주제별 학습 | |
| 13 | 동의 설정 | 교과 선생님 공개 항목 저장(만 14세 미만은 보호자 동의 안내) || ✅ 세 동의 모두 동의 상태로 보임(변경 안 함) |

> 점검 실행: 2026-11-14 14:25~14:30, 실제 모드(localhost:5176 학생01 / [::1]:5176 김교사). 공유 DB에 학습 1건·기록 2개·응시 1건·피드백 1개가 생김. 12번(교과 교사)은 이교과 로그인 후.
> 주의: 주제 선택 화면은 **주제 카드를 먼저 눌러야** "테스트 보기"가 동작한다(녹화 동선에 포함).

## 5. 녹화 팁
- 마우스는 천천히, 클릭 전 0.5초 멈춤. 입력은 미리 복사해 두고 붙여 넣기.
- 자막은 한 장면에 한 문장.
- 학생·교사 탭 전환은 컷으로 처리.

## 6. 실제 백엔드에 아직 없는 기능 (영상에 넣으려면)
| 기능 | 상태 | 영상 처리 |
|---|---|---|
| QR 인증 | 실제 배포됨(v1.0). 키오스크 탭에서 단말기 토큰을 한 번 입력해 둬야 함(팀 채널 값) | 실제 장면 사용 |
| 교과 교사(맡은 과목, 과목·반 탭) | 실제 배포됨, 데모 계정 `subject@growth-pace.test`(이교과) | 실제 장면 사용 |
| 이번 주 질문 핵심 | 실제 배포됨(v1.1), 결과 저장돼 있음. 새로 만들기는 하루 5회(오늘 1회 사용) — 녹화 전 연습으로 횟수를 쓰지 않기 | 실제 장면 사용(조회만, 새로 만들기는 1번만) |
