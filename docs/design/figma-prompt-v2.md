# Figma Make 프롬프트 v2 — 학교 행정 대시보드 스타일로 다시 그리기

아래 "프롬프트" 부분을 그대로 Figma Make에 붙여 넣는다. 참고 캡처 3장(교사 홈, 학생정보 상세, 학생 수업 활동)도 함께 올린다.

---

## 프롬프트

"성장 페이스"는 고등학생의 자기주도학습 기록과 교사의 피드백을 돕는 웹앱이다. 기능과 데이터 항목은 그대로 두고, **화면 구조·레이아웃·컴포넌트 스타일**을 첨부한 학교 행정 대시보드 캡처와 같은 수준으로 다시 디자인해 줘. 색만 바꾸는 것이 아니라 **배치, 정보 묶음, 카드 구성, 메뉴 구조, 빈 상태, 필터·탭 모양**까지 캡처의 방식을 따른다.

### 지켜야 할 것
- 앱 이름은 "성장 페이스". 캡처에 보이는 다른 서비스의 로고·이름·상표·캐릭터는 쓰지 않는다.
- 캡처 속 사람 이름·전화번호·학번 같은 실제 정보는 쓰지 않는다. 예시 데이터는 "학생01~학생30", "김교사"처럼 가명만.
- 모든 문구는 한국어 해요체. 버튼은 동사로 끝낸다("학습 시작", "피드백 남기기").
- 글자 대비 4.5:1 이상, 누르는 영역 44px 이상, 키보드 초점 표시.
- 데스크톱 1440px과 모바일 375px 프레임을 둘 다 만든다. 모바일은 왼쪽 메뉴 대신 아래 탭 바.

### 디자인 언어 (캡처에서 따올 것)
- 바탕: 아주 옅은 회색(#F7F7F9 정도). 카드: 흰색, 테두리 없음, 아주 옅은 그림자, 모서리 16~20px.
- 강조색: 진한 분홍 한 가지(흰 바탕 글자 대비 4.5:1 이상 되는 값). 강조색은 선택된 메뉴·탭, 주 버튼, 숫자 강조, 진행률 숫자에만 쓴다. 나머지는 검정·회색.
- 보조 표면: 연분홍 배너(옅은 분홍 바탕 + 분홍 제목), 연분홍 요약 패널(옅은 분홍 바탕 + 분홍 테두리).
- 버튼 3종: 분홍 채움(주), 분홍 테두리 + 분홍 글자(보조, 예 "+ 링크 추가"), 회색 테두리 작은 버튼(아이콘 + 글자, 예 "시간표 보기").
- 칩·배지: 둥근 알약 모양. 상태 칩은 옅은 바탕 + 진한 글자(예 초록 "가입 완료"). 분류 태그는 작은 진한 남색 사각 배지(예 "교과").
- 글꼴: Pretendard. 페이지 제목 28~32 굵게, 카드 제목 18 굵게, 본문 15, 보조 13 회색.
- 빈 상태: 가운데 회색 원 안 아이콘 → 굵은 한 줄 제목 → 회색 설명 두 줄 → 분홍 테두리 버튼.

### 공통 틀
- **왼쪽 사이드바(데스크톱, 폭 약 340px)**: 위에서부터
  1. 로고 줄: 앱 아이콘 + "성장 페이스", 오른쪽에 알림 종 아이콘, 사이드바 접기 아이콘.
  2. 프로필 묶음: 둥근 사각 아바타, 이름(굵게), 계정 아이디·소속(회색 두 줄), 오른쪽 더보기(⋮).
  3. 회색 테두리 큰 버튼 하나(교사: "반 바꾸기", 학생: "동의 설정").
  4. 옅은 분홍 큰 버튼 하나(교사: "전체 메뉴 살펴보기").
  5. 탭 두 개 "자주 쓰는 메뉴 | 전체 메뉴"(선택 탭은 분홍 글자 + 분홍 밑줄).
  6. 메뉴 묶음: 회색 작은 묶음 제목 아래 들여 쓴 메뉴 이름. 선택된 메뉴는 분홍 글자. 하위 메뉴가 있으면 오른쪽 꺾쇠(›).
- **본문 머리**: 왼쪽에 분홍 사각 앱 아이콘, 그 옆 작은 회색 줄(학교 · 날짜 · 시각)과 큰 인사말("안녕하세요, 김교사 선생님"). 오른쪽에 회색 테두리 "편집" 버튼.

### 화면별 요구

**교사 — 반 대시보드 (캡처 1 구조)**
- 머리 아래 넘기는 배너(연분홍, 왼쪽 위 작은 번호 태그 "02"와 분홍 작은 제목, 큰 분홍 제목, 회색 설명, 오른쪽 분홍 알약 버튼 "확인하기 ›", 아래 점 표시와 "2/6"). 배너 예: "피드백 기다리는 돌아보기 24개", "이해했다는데 점수가 낮은 학생 3명", "신고된 문제 2개".
- 그 아래 위젯 카드 격자:
  - "챙길 학생"(넓은 카드, 오른쪽 위 톱니): 숫자 타일 4개 — 지금 학습 중 / 이야기 나눠 볼 학생 / 피드백 기다림 / 채점 확정 대기. 타일은 작은 아이콘 칩 + 이름 + 큰 숫자 + 회색 설명. 주의가 필요한 타일은 옅은 분홍 바탕 + 분홍 테두리.
  - "바로가기"(빈 상태 예시), "메모"(빈 상태 예시).
  - "학생 학습 현황"(넓은 카드): 오른쪽 위 작은 회색 테두리 버튼 "반 분석 ›", 큰 숫자 + "명 · 최근 7일", 얇은 막대, 아래 범례(학습함·안 함·피드백 기다림), 요일 칩 줄(전체·월·화·수·목·금, 선택 칩은 진한 회색 채움).
  - "질문 유형"(카드): 알약 칩 가로 줄(개념·확인·답 요청·기타, 선택 칩은 분홍 채움).
- 오른쪽 열(폭 약 360px): "11월 14일 (토)" 큰 날짜 + 분홍 "오늘" 칩. 묶음마다 제목 + 오른쪽 작은 회색 테두리 버튼(아이콘 + 글자) + 회색 한 줄. 묶음: "오늘 학습 중" / "최근 신고" / "피드백 기다림" / "일정"(색 점 + 기간 + 제목).
- 학생 표는 대시보드 아래 카드로: 번호, 이름, 학습 횟수, 시간, 남은 질문, 최근 테스트, 최근 학습, 상태 배지, 한 줄 판단(회색 작은 글자, 예 "확인 테스트 정답률 낮음 · 20%"). 이름·번호 검색, 10명씩 쪽 나눔.

**교사 — 학생 상세 (캡처 2 구조, 3열)**
- 가운데 목록 열(폭 약 400px): "학생 목록" 제목, 필터 드롭다운 두 개(반, 정렬), 분홍 테두리 정렬 아이콘 버튼, 검색칸. 목록 행은 "학생09 2학년 3반 9번" 굵게, 선택 행은 옅은 회색 바탕.
- 오른쪽 상세 열: 위에 가로 탭 "요약 | 학습 기록 | AI 질문 | 주제 성장 | 피드백"(선택 탭은 진한 글자 + 진한 밑줄).
- 카드 "학생정보": 제목 옆 상태 칩(예 "기록 공유 동의", 미동의면 회색 "기록 비공개"), 오른쪽 위 회색 버튼 "열람 기록" + 분홍 채움 버튼 "피드백 남기기". 왼쪽 큰 사각 아바타 자리(회색 사람 모양), 오른쪽 2열 이름표–값(번호, 최근 학습, 학습 횟수, 학습 시간, 최근 테스트, 남은 질문).
- 카드 "한눈에 보기": 판단 문장 목록. 줄마다 왼쪽 상태 칩(챙길 점·좋은 점·참고), 굵은 문장, 회색 근거 숫자, "→ 할 일" 한 줄.
- 카드 "주제별 성장": 표(주제, 학습 횟수, 첫 정답률 → 최근 정답률, 신호 칩).

**교사 — 반 분석, 신고된 문제**
- 같은 카드 언어로. 반 분석은 분포 막대 카드 3개(학습 시간·정답률·AI 질문 수) + 주제 TOP 5 표 + 질문 유형 비율 막대.
- 신고된 문제는 문항 카드 목록(주제 태그, 상태 칩, 문항, 선택지에서 정답 표시, 해설, "AI 1차 검토: 문제 없음/오류 있음 · 이유", "이 문항 신고 n번", 신고 학생 번호) + 카드 아래 버튼 두 개("문항 제외", "신고 기각·재채점") + 맨 아래 "학생별 신고 수" 표.

**학생 — 홈·내 기록 (캡처 3 구조)**
- 학생 사이드바는 짧게: 프로필(이름 · 번호, 회색 한 줄), 회색 테두리 버튼 "동의 설정", 메뉴 묶음 "학습"(홈, 학습 시작, 내 기록, 내 정리).
- 페이지 제목 + 회색 설명 한 줄.
- 연분홍 요약 패널(분홍 테두리): 제목 "오늘 할 일이 **2**개 있어요"(숫자만 분홍), 오른쪽 "전체보기 ›". 칩 두 개(선택: 분홍 테두리 "새 피드백 1", 회색 "남은 질문 3"), 회색 설명, 빈 상태 가운데. 패널 오른쪽 아래 분홍 채움 "학습 시작".
- "주제별 성장" 구역: 왼쪽 필터 드롭다운(분홍 테두리 "기간 최근 4주", 회색 "과목 전체"), 오른쪽 검색칸. 카드 3열: 왼쪽 위 남색 작은 태그(과목), 오른쪽 위 회색 단원명, 굵은 주제 이름 + 분홍 원 숫자(새 피드백 수), 회색 설명 두 줄, 얇은 진행 막대 + 오른쪽 분홍 % (최근 정답률), 아래 칩 두 개(연분홍 "남은 질문 1개", 회색 "테스트 2번").
- 내 기록: 탭 "학습 목록 | 내 정리". 학습 목록은 왼쪽 목록 + 오른쪽 상세(학습 과정 타임라인, 돌아보기, 선생님 피드백). 내 정리는 검색칸 + "아직 남은 질문" 카드 + 학습별 카드(메모·궁금한 점·나만 보기 배지, 돌아보기 요약).

**학생 — 학습 중, 학습 마치기, 테스트**
- 학습 중: 위에 고정 바(학습 중 칩, 시작 시각·목표, 경과 시간, "학습 끝내기"). 왼쪽 열: 기록 입력 카드(탭 메모·궁금한 점·짧은 테스트·종이에 기록, 입력칸, 공개 범위 "교사 공개 / 나만 보기", 분홍 "기록하기") + "오늘의 기록" 타임라인. 오른쪽 열: AI 학습 도우미 카드(설명 "개념은 바로 설명하고, 문제의 최종 답은 스스로 찾도록 도와요", 개인정보 안내 띠, 대화 말풍선, 입력칸). 모바일 순서: 입력 → AI → 기록.
- 학습 마치기: 주제 선택 카드(AI 자동 분류 · 참고용, 근거 기록 인용) → 테스트 5문항 카드(문항마다 "이 문제 이상해요", 신고 결과 안내 띠) → 결과(점수, 해설) → 돌아보기(체크리스트, 이해도 3단계, 남은 질문, 메모).
- 테스트 대기: 가운데 스피너 + 단계 문구("기록에서 주제를 확인하고 있어요 · 보통 10초쯤 걸려요" → "문항 5개를 만드는 중이에요" → "거의 다 됐어요").

**공통 — 로그인, 동의, 키오스크**
- 로그인: 왼쪽 큰 소개 문구, 오른쪽 흰 카드(학교 계정 로그인 / 데모 계정 고르기).
- 동의: 항목별 카드(얼굴 인증, AI 사용, 기록 공유), 켜고 끄기, 만 14세 미만 보호자 동의 안내, 아래 "내 기록을 본 사람" 목록.
- 키오스크: 큰 글자, 가운데 인증 안내, QR 입력칸.

### 상태
- 화면마다 로딩(스켈레톤), 빈 상태, 오류(회색 원 아이콘 + 문구 + "다시 시도"), 권한 없음(기록 공유 미동의 학생: "기록 비공개" 칩 + 회색 안내) 상태 프레임을 함께 만든다.

### 결과물
- 위 화면들의 데스크톱·모바일 프레임.
- 컴포넌트 세트: 사이드바(교사·학생), 본문 머리, 배너, 위젯 카드, 숫자 타일, 빈 상태, 목록 행, 탭, 필터 드롭다운, 칩·배지, 버튼 3종, 진행 막대, 표, 판단 문장 줄, 말풍선.
- 색·글자·간격·모서리·그림자 토큰 표.
